# GitHub Sync Rule

Setiap kali selesai melakukan perubahan kode atau fitur pada website ini:
1. Selalu ingatkan pengguna bahwa ada perubahan lokal yang siap diperbarui ke GitHub.
2. Selalu tanyakan kepada pengguna: "Apakah perubahan ini ingin langsung di-push ke GitHub agar website live ter-update sekarang?"
3. Hanya lakukan commit & push ke GitHub setelah pengguna memberikan konfirmasi/persetujuan.
